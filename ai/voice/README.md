# SER training data pipeline (Stage 1)

Builds one multi-lingual emotional-speech manifest for the Stage 2 fine-tune of
`facebook/wav2vec2-xls-r-300m`.

## Unified label space (7)

`angry · disgust · fear · happy · neutral · sad · surprise`

Extra corpus classes (calm, boredom, enthusiasm, …) are dropped. See
`labels.py` for the per-corpus mapping.

## Run

```bash
# 1. fetch the auto corpora (RAVDESS/CREMA-D reused from ai/training/datasets/ if present)
python -m ai.voice.download --corpus all

# 2. (optional) drop any manually-obtained corpora into ai/training/ser/raw/<key>/

# 3. normalise everything -> ai/training/ser/processed/ + ai/training/ser/manifest.csv
python -m ai.voice.prepare
```

`raw/` and `processed/` are git-ignored. `manifest.csv` holds absolute paths and
is regenerated by `prepare.py`, so it is git-ignored too.

## Manifest columns

`path, emotion, label_id, corpus, language, speaker, split`

Split is speaker-independent (~80/10/10 per corpus, deterministic hash of the
speaker id). The `language` column lets Stage 2 run leave-one-language-out eval.
